# 房市決策參考的資料定義

這份報告提供買賣判斷所需的市場證據，不自動決定買賣時機、房屋估值或掛牌價。DOM、成交結果與開價參考有用，但必須同時看樣本、日期、房型及資料取得限制。

## 零成交不能直接當成市場冷清

2026-11-10 的有限對照查詢發現：相同地理範圍與一年窗口下，嚴格屬性查詢為零，拿掉土地條件仍為零，而純地理房屋紀錄查詢有 70 筆附交易日期與價格的紀錄。它們包含不同房型，不是 70 筆合適可比成交。另有同地址案例在掛牌來源為 Townhouse、房屋紀錄為 Condo，顯示跨來源分類會排除資料。

因此程式先取得地理／日期範圍內的房屋紀錄，再套用明確的可比條件。依目前政策僅保留相符的 SFH 或 Townhouse；已知 Condo 與尚未釐清的 Condo／Townhouse 衝突排除，不另設 Condo 參考區。未知房型不併入同類。取回原始筆數、獨立候選與符合條件的有效筆數不是同一種分母。

搜尋每類預設最多三頁，每頁最多 500 筆。到上限但尚未證明讀完時顯示不完整。所有頁數讀完仍不等於供應商完整涵蓋市場。失敗、成功但無資料、篩選後無合適資料及截斷是不同情況。

## DOM

目前顯示的是掛牌來源提供的非負整數 DOM，包含合法的 0，附上最後觀察日期。沒有有效值就顯示未提供，不把缺值改成零，也不用上市至今天的日數替代。

它不是已確認的上市到簽約或上市到成交時間。Redfin Data Center 的 median DOM 是當期進入合約物件由上市至進入合約的日數中位數，與現有待售物件的觀察值不是同一個母體。[Redfin 方法](https://www.redfin.com/news/data-center/methodology/)

## 成交價與開價落差

標準的成交／最後開價比、成交／原始開價比需要同一房源、戶別和掛牌週期的確認資料。不能把新的開價、重新掛牌價或其他歷史開價配上舊成交。

本版提供較保守的「具日期的售前開價參考落差」：

- 差額＝來源成交價－售前開價參考。
- 百分比＝差額÷正數開價參考×100%。
- 必須保留同一房源／戶別的來源證據、MLS 掛牌週期、上市與觀察及下架日期。
- 日期順序為上市≤觀察≤下架≤交易，觀察距交易最多 90 天。
- 不能有另一個衝突／介入的掛牌週期、同日矛盾價格或售後開價配對。
- 缺少或有疑義時不計算。90 天是保守配對規則，不是對房市的統計結論。

例如成交 $900,000、具日期的參考開價 $1,000,000，落差為 −$100,000／−10%。報表明確標示這不是已確認的最後／原始開價比，也不能稱作議價折扣。沒有計算全市場中位數、熱度分數或漲跌結論。

## Redfin 導覽與資料取得

有來源提供且格式安全的 Redfin 房源網址時，提供該連結並提醒核對地址。否則自動產生明確標示的 Google `site:redfin.com` 地址搜尋；不假裝是已確認房源頁，也不捏造 Redfin property ID。搜尋結果可能缺漏或配錯，使用者可核對顯示的完整地址。[官方搜尋說明](https://support.redfin.com/hc/en-us/articles/45454725122075-Searching-for-a-property-or-address)

Redfin 有官方區域統計下載，包括 DOM 與不同開價比，但不是單筆房源 API。尚未驗證所需城市／房型的實際資料列，不能把區域值當成這間房的行情。[下載入口](https://www.redfin.com/news/data-center/downloads/)

截至 2026-11-10，未找到可直接採用的官方單筆房源 API 或穩定任意地址搜尋 URL 合約。這是未找到，不是證明不存在。Redfin 條款第 2.3.5 節要求自動查詢取得書面許可；未找到適用的自動下載例外或本用途授權，因此本版不抓內部端點、不繞過 CAPTCHA、不實作自動爬取，也不把第三方 scraper 當成官方 API。[Redfin 條款](https://www.redfin.com/about/terms-of-use)

目前 Redfin 直接連結、MLS 優先與雙來源保存規則詳見 [來源比對政策](redfin-evidence.md)。舊版使用 Google 備援的說明僅適用於尚未核對的地址；已核對地址優先直接連至房源頁。
